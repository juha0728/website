# Vitality

A personal health and wellness web app. People check in on their day, build a health profile, and find educational ideas for food and exercise.

Portfolio case study: https://juha0728.github.io/website/

> **Educational information only.** Vitality is not a substitute for professional medical advice, diagnosis, or treatment. Always talk to a qualified healthcare professional about your health or any symptoms.

## What the site includes

- Pages: Dashboard, My Health Profile, Daily Check-In, Diet, Exercise, Statistics and Settings
- A dashboard with a welcome message, search, an educational notice, a featured meal, a weekly check-in tracker and a health profile completion bar
- Guest mode, where data stays on the computer

## About `app.jsx`

`app.jsx` is an early prototype built from the project's written brief. It differs from the current site.
